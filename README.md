# 🛡️ MediaGuard v6.0.0 for Joomla 5 / 6

**MediaGuard** is an advanced, powerful, and ultra-lightweight system plugin designed to provide absolute, uncompromising protection for directory structures and assets within Joomla's native **Media Manager (com_media)**. 

Engineered strictly around the **PSR-4** object-oriented architecture and hardware-optimized methods, it ensures maximum security layout control without adding any overhead to server CPU or browser RAM.

---

## 🚀 Key Features & Hybrid Architecture

* **Bulletproof REST API Shield (Backend Security):** MediaGuard operates seamlessly at the core system level, intercepting asynchronous network requests generated by the Vue.js Media Manager. It detects and strictly blocks destructive HTTP `PUT` and `DELETE` requests aimed at messing with protected zones. Even if a user bypasses the UI, the backend instantly kills the transaction with a hard 403 Forbidden status.
* **Dual-Layer Visual Defense System (Hardware-Accelerated CSS):**
  * **State 1: Closed Protected Zone (Padlock 🔒):** Folders explicitly listed in the database are fully locked down. Selection checkboxes and the "three-dots" action menus are removed. Inside the folder, the top action toolbar is disabled, the Drag & Drop upload container is neutralized, and a custom security warning banner is displayed.
  * **State 2: Access Corridor (Blue Shield 🛡️):** The plugin automatically calculates directory paths and detects parent directories leading to deep protected zones. It securely locks parent folders from being deleted or renamed (removing checkboxes and delete/rename dropdown actions) while leaving file selection, file uploads, and safe subfolder interactions fully functional inside them!
* **Smart Drag & Drop Eater:** Any unauthorized attempt to drop files into a locked zone is suppressed at the highest `window` event capturing hierarchy level. This stops the upload process instantly before it registers, saving server bandwidth and preventing unnecessary 403 network error loops.
* **0% CPU Idle Overhead:** Free from bloated JavaScript string processing or heavy loop recalculations. Layout adjustments are handled natively by a zippy stylesheet combined with CSS Custom Properties (`style.setProperty`), leveraging the client's GPU for optimal interface fluidity.
* **Next-Gen Compatibility (Future-Proof):** Operates stably across Joomla 5, and thanks to utilizing native `CMSPlugin` class automated event discovery hooks, it integrates flawlessly into clean **Joomla 6.x** environments with zero Legacy layer dependencies.

## 🛠️ Installation & Configuration

1. Download your compiled `mediaguard.zip` package.
2. Log in to your Joomla Administrator control panel.
3. Navigate to: **System** -> **Manage** -> **Extensions** (J5) or the native Upload installer view in Joomla 6.
4. Upload and install the ZIP archive.
5. Head over to: **System** -> **Manage** -> **Plugins**, and search for **System - MediaGuard**.
6. Toggle the status icon to **Enable (green checkmark)** and click to edit its properties.
7. Configure the following parameters:
   * **Protected folders:** Type target folder paths (e.g., `Articles`, `Banners`) line-by-line. The plugin normalizes inputs across system storage adapters automatically (e.g., `local-images:/articles`).
   * **Alert Message Text:** Enter a custom warning text to show on the red top bar inside locked zones. If left empty, a robust default warning will be utilized.
   * **White List (Group IDs):** Specify comma-separated User Group IDs exempt from security rules (e.g., `5,6,7`). Super Users and listed groups maintain full development write access.
   * **Debug Mode:** Activating this injects a lightweight counter onto the frontend tracking active protection rules for layout checks. **Set to No (JNO) for live production sites**.
8. Click **Save & Close**.

## 🚨 Emergency Recovery Procedure (Fail-Safe)

If cache locks occur on highly restrictive production hosting environments, or a third-party extension conflict locks you out of the admin panel after a rule update, perform these simple data rescue steps:

1. Log in to your server database via **phpMyAdmin**.
2. Locate the `_extensions` table (where `_` represents your site's custom database prefix).
3. Find the entry matching `element = "mediaguard"` and `folder = "system"`.
4. Edit the row and change the **`enabled`** column value from `1` to **`0`**.
5. Save changes. The extension is instantly decoupled at the system core level, restoring full control of your site backend immediately.
